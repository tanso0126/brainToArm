brainToArm WINDOWS 통합 운영실 빠른 시작
=========================================

처음 사용하는 경우 아래 순서대로 진행하세요.

0) 압축 풀기
   - ZIP 안에서 실행하지 말고 전체 압축을 새 폴더에 완전히 풉니다.
   - firmware와 windows_release 폴더가 같은 brainToArm 폴더 안에 있어야 합니다.

1) Arduino 펌웨어
   - OPEN_FIRMWARE.bat을 더블클릭합니다.
   - Arduino IDE에서 보드를 Arduino Uno로 선택합니다.
   - Uno의 COM 포트를 선택하고 업로드 버튼을 누릅니다.
   - 업로드 후 Serial Monitor와 Serial Plotter를 닫습니다.

2) PC 최초 설치(처음 한 번만)
   - 인터넷에 연결합니다.
   - SETUP_WINDOWS.bat을 더블클릭합니다.
   - 초록색 설치 완료 문구가 나올 때까지 창을 닫지 않습니다.

3) 매번 실행
   - PolyG-I, 손목 웹캠, Uno USB, 충전된 외부 서보 전원을 연결합니다.
   - START_CONTROL_CENTER.bat을 더블클릭합니다.
   - 화면에서 PolyG-I 측정 -> 카메라 연결 -> Uno 연결 순서로 누릅니다.
   - 다중 물체 찾기 -> 후보 선택 -> 선택 후보 자동 파지를 누릅니다.

4) 뇌파 없이 먼저 확인
   - 3D 시뮬레이션 탭은 실물 장치 없이 사용할 수 있습니다.
   - 물체를 놓고 자동 실행한 뒤 '아니야' 버튼으로 후보 전환을 확인합니다.

카메라나 COM 포트를 자동으로 잘못 고르는 경우:
  통합 운영실 아래쪽 설정에서 카메라 번호와 COM 포트를 저장합니다.

문제가 생기면:
  1. DIAGNOSE.bat을 실행합니다. 이 도구는 로봇팔을 움직이지 않습니다.
  2. 창 전체가 나오게 사진을 찍습니다.
  3. 통합 운영실의 실행 기록과 README_WINDOWS.md 문제 해결을 확인합니다.
